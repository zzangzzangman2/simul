# 카지노 LIVE 런타임 배경

이 폴더의 4종은 2026-08-05 built-in ImageGen으로 생성한 정식 런타임 자산이다.
플레이어가 현장에 방문하는 장면이 아니라 작업실 PC의 요원 전용 실시간 중계 화면으로
사용한다. 인물·실제 상표·읽을 수 있는 간판·현금 이미지는 넣지 않는다.

공통 프롬프트:

- `stylized-concept`, 2:3 세로 모바일 게임 배경
- 2000년대 후반 서울의 가상 고급 카지노
- 고밀도 소프트 페인터리 2D 비주얼노벨 환경, 사진·3D 금지
- 다크 월넛·버건디·브라스·에메랄드 펠트, 절제된 앰버 조명
- 하단은 Flutter 베팅 UI가 올라갈 수 있도록 어둡고 정돈된 여백
- 인물·손·실제 상표·읽을 수 있는 문구·워터마크·현대 터치스크린 금지

파일별 요청:

- `bg_decimal_casino_lobby_2010_v1.png`: 로비와 여러 테이블 살롱으로 이어지는 중앙 동선
- `bg_decimal_casino_baccarat_2010_v1.png`: 플레이어 좌석 시점의 빈 바카라 테이블
- `bg_decimal_casino_roulette_2010_v1.png`: 싱글 제로 유럽식 룰렛 휠과 베팅 테이블
- `bg_decimal_casino_table_games_2010_v1.png`: 전경 블랙잭 테이블과 후경 다이사이 테이블

## 여성 딜러 손 오버레이

2026-08-05 built-in ImageGen으로 같은 성인 여성 딜러의 손 2종을 만들고, 균일한
`#00ff00` 배경을 로컬 크로마키 제거한 투명 PNG다. 손은 플레이어가 직접 카지노에
방문했다는 뜻이 아니라 요원 PC로 보는 라이브 중계 화면의 딜러 동작이다.

- `dealer_hand_deal_v1.png`: 위에서 내려다본 카드 배분용 오른손. 가느다란 손가락,
  짧고 단정한 투명 누드 네일, 흰 셔츠 커프스와 검정 조끼 소매를 사용한다.
- `dealer_hand_collect_v1.png`: 같은 딜러의 카드 회수·칩 정리용 왼손.

최종 프롬프트 공통 핵심:

- `stylized-concept`, 프리미엄 모바일 카지노 애니메이션용 투명 오버레이 원본
- 성인 한국인 여성 딜러의 단정하고 아름다운 손, 자연스러운 다섯 손가락 해부학
- 탑다운 카메라, 소프트 렌더 비주얼노벨 게임 자산, 따뜻한 카지노 조명
- 과한 네일·긴 손톱·네일아트·장신구·장갑·소품·문자·로고 금지
- 완전 균일한 `#00ff00` 배경, 그림자·반사·바닥·그라데이션 금지

크로마키 후처리는 `remove_chroma_key.py --auto-key border --soft-matte --despill
--edge-contract 1`을 사용했으며 네 모서리 알파와 피사체 범위를 확인했다.

## 게임 선택 카드 아트

2026-08-05 built-in ImageGen으로 생성한 세로형 선택 카드 아트다. 원본을 모바일
표시 크기에 맞춰 `720×960` WebP를 기본으로 사용하며, 크랩스 타일은 원본 PNG를 쓴다. 한글 제목과
배당은 이미지가 아니라
Flutter 텍스트로 올려 정확한 표기와 접근성을 유지한다.

- `tile_casino_baccarat_v1.webp`: 버건디 카드 뒷면과 아이보리·금장 칩
- `tile_casino_blackjack_v1.webp`: 스페이드 카드와 검정·금장 칩
- `tile_casino_roulette_v1.webp`: 다크 월넛 유럽식 휠과 아이보리 볼
- `tile_casino_craps_v1.png`: 에메랄드 크랩스 매트, 추상 금색 라인, 반투명 루비 레드 주사위 2개
- `tile_casino_sicbo_v1.webp`: 아이보리 주사위 3개와 검정 옻칠 주사위 컵
- `tile_casino_slots_v1.webp`: 체리·벨·다이아몬드·클로버 3릴 머신

공통 프롬프트 핵심은 `stylized-concept`, 프리미엄 모바일 카지노 게임 선택 카드,
상단 60%에 게임 상징 집중, 하단 35%는 한글 UI용 어두운 여백, 에메랄드·버건디·
검정·아이보리·앤티크 골드 팔레트, 소프트 페인터리 2.5D 런타임 아트다. 이미지 내부
문자·숫자·로고·워터마크·사람·손·휴대폰 목업은 금지했다.

크랩스 타일 최종 프롬프트는 `stylized-concept`, 3:4 세로형 프리미엄 모바일 카지노
선택 카드, 에메랄드 펠트의 크랩스 테이블 클로즈업, 추상 금색 라인워크, 반투명 루비 레드
주사위 정확히 2개, 버건디·아이보리 칩, 사람·손·문자·로고 금지였다.
