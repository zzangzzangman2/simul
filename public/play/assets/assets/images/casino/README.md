# 카지노 런타임 배경과 딜러 장면

이 폴더의 환경 배경과 딜러 장면은 2026-08-05 built-in ImageGen으로 생성한 정식
런타임 자산이다. 플레이어는 2010년 성인 시점부터 현장에 직접 입장하며 실제 상표와
읽을 수 있는 간판은 사용하지 않는다.

## 입장 딜러 장면

동일한 20세 성인 여성의 얼굴·갈색에서 밝은 금갈색으로 이어지는 땋은 머리·호박색 눈·
흰색 오프숄더 로브형 미니드레스·맨발·밝은 피부와 자연스러운 성인 체형을 유지한다.

- `dealer_entry_welcome_age20_v1.png`: 입구 정면 환영
- `dealer_chip_exchange_age20_v1.png`: 고개를 내려 칩을 분류하는 교환 작업
- `dealer_chip_handover_age20_v2.png`: 몸을 자연스럽게 숙여 칩 트레이 전달
- `dealer_table_guide_age20_v1.png`: 로비에서 테이블 안내

Flutter 공통 비주얼노벨 대화창은 입장·교환·전달·6개 게임 상황에 맞는 대사를
한 줄씩 표시하며 딜러 이안은 플레이어를 `오빠`라고 부른다. 첫 대사는 현장 입장
맥락에 맞춰 구성하며 나이는 UI에 표기하지 않는다.

공통 프롬프트:

- `stylized-concept`, 2:3 세로 모바일 게임 배경
- 2000년대 후반 서울의 가상 고급 카지노
- 고밀도 소프트 페인터리 2D 비주얼노벨 환경, 사진·3D 금지
- 다크 월넛·버건디·브라스·에메랄드 펠트, 절제된 앰버 조명
- 하단은 Flutter 베팅 UI가 올라갈 수 있도록 어둡고 정돈된 여백
- 인물·손·실제 상표·읽을 수 있는 문구·워터마크·현대 터치스크린 금지

파일별 요청:

- `bg_decimal_casino_lobby_2010_v1.png`: 로비와 여러 테이블 살롱으로 이어지는 중앙 동선
- `bg_decimal_casino_baccarat_2010_v1.png`: 플레이어 좌석 시점의 빈 바카라 테이블
- `bg_decimal_casino_roulette_2010_v1.png`: 싱글 제로 유럽식 룰렛 휠과 베팅 테이블
- `bg_decimal_casino_table_games_2010_v1.png`: 전경 블랙잭 테이블과 후경 다이사이 테이블

## 여성 딜러 손 오버레이

2026-08-05 built-in ImageGen으로 같은 성인 여성 딜러의 손 2종을 만들고, 균일한
`#00ff00` 배경을 로컬 크로마키 제거한 투명 PNG다. 현장 테이블의 카드 배분·회수
동작에 사용한다.

- `dealer_hand_deal_v1.png`: 위에서 내려다본 카드 배분용 오른손. 가느다란 손가락,
  짧고 단정한 투명 누드 네일, 흰 셔츠 커프스와 검정 조끼 소매를 사용한다.
- `dealer_hand_collect_v1.png`: 같은 딜러의 카드 회수·칩 정리용 왼손.

최종 프롬프트 공통 핵심:

- `stylized-concept`, 프리미엄 모바일 카지노 애니메이션용 투명 오버레이 원본
- 성인 한국인 여성 딜러의 단정하고 아름다운 손, 자연스러운 다섯 손가락 해부학
- 탑다운 카메라, 소프트 렌더 비주얼노벨 게임 자산, 따뜻한 카지노 조명
- 과한 네일·긴 손톱·네일아트·장신구·장갑·소품·문자·로고 금지
- 완전 균일한 `#00ff00` 배경, 그림자·반사·바닥·그라데이션 금지

크로마키 후처리는 `remove_chroma_key.py --auto-key border --soft-matte --despill
--edge-contract 1`을 사용했으며 네 모서리 알파와 피사체 범위를 확인했다.

## 게임 선택 카드 아트

2026-08-05 built-in ImageGen으로 생성한 세로형 선택 카드 아트다. 원본을 모바일
표시 크기에 맞춰 `720×960` WebP를 기본으로 사용하며, 크랩스 타일은 원본 PNG를 쓴다. 한글 제목과
배당은 이미지가 아니라
Flutter 텍스트로 올려 정확한 표기와 접근성을 유지한다.

- `tile_casino_baccarat_v1.webp`: 버건디 카드 뒷면과 아이보리·금장 칩
- `tile_casino_blackjack_v1.webp`: 스페이드 카드와 검정·금장 칩
- `tile_casino_roulette_v1.webp`: 다크 월넛 유럽식 휠과 아이보리 볼
- `tile_casino_craps_v1.png`: 에메랄드 크랩스 매트, 추상 금색 라인, 반투명 루비 레드 주사위 2개
- `tile_casino_sicbo_v1.webp`: 아이보리 주사위 3개와 검정 옻칠 주사위 컵
- `tile_casino_slots_v1.webp`: 체리·벨·다이아몬드·클로버 3릴 머신

공통 프롬프트 핵심은 `stylized-concept`, 프리미엄 모바일 카지노 게임 선택 카드,
상단 60%에 게임 상징 집중, 하단 35%는 한글 UI용 어두운 여백, 에메랄드·버건디·
검정·아이보리·앤티크 골드 팔레트, 소프트 페인터리 2.5D 런타임 아트다. 이미지 내부
문자·숫자·로고·워터마크·사람·손·휴대폰 목업은 금지했다.

크랩스 타일 최종 프롬프트는 `stylized-concept`, 3:4 세로형 프리미엄 모바일 카지노
선택 카드, 에메랄드 펠트의 크랩스 테이블 클로즈업, 추상 금색 라인워크, 반투명 루비 레드
주사위 정확히 2개, 버건디·아이보리 칩, 사람·손·문자·로고 금지였다.

## 현장 플레이 테이블 배경

2026-08-05 built-in ImageGen으로 실제 플레이 화면용 가로 테이블 배경 6종을 별도로
생성했다. 원본은 `1536×1024`이며 모바일 표시용 `1024×682` 고품질 WebP로 저장했다.
카드·휠·볼·주사위·칩·릴 결과는 이미지에 굽지 않고 Flutter 애니메이션으로 올린다.
`live_table_*`은 구형 파일명일 뿐이며 게임 설정은 플레이어가 카지노 현장에
직접 입장하는 방식이다.

- `live_table_baccarat_v1.webp`: 금색 베팅 아크와 두 카드 존의 바카라 테이블
- `live_table_blackjack_v1.webp`: 반원형 베팅 존과 카드 슈가 있는 블랙잭 테이블
- `live_table_roulette_v1.webp`: 원형 휠 크래들과 추상 베팅 그리드의 유럽식 룰렛
- `live_table_craps_v1.webp`: 깊은 패딩 레일과 중앙 롤링 레인의 크랩스 테이블
- `live_table_sicbo_v1.webp`: 중앙 팔각 주사위 트레이의 다이사이 테이블
- `live_table_slots_v1.webp`: 검정 옻칠·황동·버건디 3릴 머신 프레임
- `live_roulette_wheel_v1.webp`: 번호와 볼을 제외한 다크 월넛·황동 룰렛 회전 원판

공통 프롬프트는 `stylized-concept`, 플레이어 좌석의 약간 높은 시점, 고밀도 2.5D
비주얼노벨 게임 아트, 다크 월넛·브라스·에메랄드·버건디 팔레트, 중앙 결과 영역 확보,
사람·딜러·손·카드·주사위·칩·볼·문자·숫자·로고·워터마크 금지였다.
룰렛 원판도 같은 방식으로 별도 생성하고 실제 볼은 Flutter 회전 애니메이션으로 올린다.

## 3릴 슬롯 심벌 아틀라스

`slot_symbol_atlas_v1.png`는 2026-08-05 built-in ImageGen으로 만든 투명 배경의
정식 슬롯 심벌 자산이다. `1536×1024` 캔버스를 같은 크기의 `3×2` 칸으로 나눴으며
순서는 위쪽 `체리·레몬·스타`, 아래쪽 `BAR·벨·7`이다. Flutter는 각 릴의 실제 엔진
결과 인덱스로 해당 칸을 잘라 표시하므로 그림과 당첨 판정이 일치한다. 회전 중에도 같은
여섯 그림을 순환하며 텍스트·이모지 대체 심벌은 사용하지 않는다.

최종 프롬프트 핵심:

- `stylized-concept`, 프리미엄 모바일 클래식 3릴 카지노용 프로덕션 심벌 아틀라스
- 정확한 `3열×2행`, 위 `체리·레몬·골드 스타`, 아래 `BAR·브라스 벨·루비 7`
- 아이보리·버건디·앤티크 골드·검정 옻칠의 소프트 페인터리 2.5D 재질
- 각 심벌의 크기·조명·여백을 통일하고 칸 밖으로 넘기지 않음
- `BAR`와 `7` 이외의 문자·숫자·사람·손·칩·카드·로고·워터마크 금지
- 균일한 `#00ff00` 크로마 배경으로 생성한 뒤 로컬에서 투명 PNG로 후처리

## 블랙잭 액션 아이콘 아틀라스

`blackjack_action_atlas_v1.png`는 2026-08-05 built-in ImageGen으로 만든 투명 배경의
블랙잭 액션 아이콘 자산이다. 한 줄 3칸 순서로 `히트·스탠드·더블`을 담았으며 히트는
추가로 날아오는 카드, 스탠드는 금색 정지 손바닥 메달, 더블은 같은 크기의 칩 두 묶음과
카드 두 장으로 구분한다. Flutter가 각 칸을 잘라 버튼에 표시하고 한글·영문 액션명은
정확성을 위해 이미지가 아니라 런타임 텍스트로 올린다.

최종 프롬프트 핵심:

- `stylized-concept`, 프리미엄 모바일 블랙잭용 3칸 프로덕션 UI 아이콘 아틀라스
- 왼쪽 추가 카드와 금색 진행 화살표, 가운데 정지 손바닥 메달, 오른쪽 두 칩 묶음과 카드
- 버건디·아이보리·앤티크 골드의 소프트 페인터리 2.5D 카지노 재질
- 36px 표시에서도 구분되는 실루엣, 칸별 동일한 무게와 충분한 여백
- 문자·숫자·인물·로고·워터마크·버튼 프레임 금지
- 균일한 `#00ff00` 크로마 배경으로 생성한 뒤 로컬에서 투명 PNG로 후처리

## 룰렛 베팅 아이콘 아틀라스

배경의 룰렛 외부 베팅 아이콘 자산이다. 정확한 `3열×2행` 순서로 위쪽
`1–18·짝수·레드`, 아래쪽 `블랙·홀수·19–36`을 담는다. Flutter가 각 칸을 잘라
48px 높이의 베팅 버튼에 표시하며 한글 종류와 지급 배수는 런타임 텍스트로 올린다.

최종 프롬프트 핵심:

- 낮은 구간은 아래 화살표가 있는 휠, 짝수는 균형 잡힌 칩 두 개, 레드는 루비 칩
- 블랙은 금색 스페이드의 검정 칩, 홀수는 비대칭 칩 세 개, 높은 구간은 위 화살표 휠

- 균일한 `#00ff00` 크로마 배경으로 생성한 뒤 `soft-matte·despill·edge-contract 1`로
