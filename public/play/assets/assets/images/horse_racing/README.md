배경 생성 프롬프트는 2000년대 한국 오후 경마장, 관중석·그랜드스탠드·인필드·연못·
8개 주로 밴드·출발 게이트·아날로그 전광판을 요구하고 말·문자·로고를 금지했다. 질주
시트 프롬프트는 측면 전신, 8개의 서로 다른 실제 갤럽 단계, 일관된 말·기수 디자인,
고정 카메라와 평면 크로마 배경을 요구했다. 시트는 생성 후 크로마 제거·디스필·소프트
매트 처리를 거쳐 투명 PNG로 저장했다.

직선 주로 v2는 `stylized-concept` 모드에서 완전한 정측면·직교 카메라, 끝까지 수평이며
서로 평행한 8개 흙 레인, 긴 횡스크롤 구도, 2000년대 서울 외곽 풍경을 요구했다. 원근
수렴·대각선·커브·말·기수·출발 게이트·결승선·문자·로고·워터마크는 금지했다.
런타임 v4는 v2를 `precise-object-edit` 대상으로 사용해 오른쪽 끝에만 좁은 체크 결승선을
흙바닥 원근과 질감에 맞춰 직접 새겼다. 카메라는 이 한 장의 파노라마를 이동하므로 결승선이
별도 UI처럼 밀려오지 않고 배경 끝과 함께 자연스럽게 드러난다.

런타임 패독 v4와 포토피니시 v2는 기존 경마장 배경과 박하은 원화를 스타일 참조로 고정한
built-in ImageGen `stylized-concept` 자산이다. 패독은 8두·8기수·핸들러가 안전 여백 안에서
행진하고, 포토피니시는 완전한 정측면에서 선두가 잘리지 않은 채 8두가 장애물 없이 결승선을
통과한다. 결과표 v1은 기존 결과 화면을 레이아웃 참조로 삼아 8개 빈 기록 행을 정확히 만들고
문자·번호는 모두 비웠다. 마명·기록·배당은 Flutter가 실제 데이터와 Maplestory 글꼴로 합성한다.

창구 직원 4장은 사용자 외형 원본을 캐릭터 기준, 박하은 정식 원화를 화풍 기준, 카지노 딜러의
환영·안내·교환·전달 장면을 화면 구성 기준으로 분리해 참조했다. 얼굴·검은 트윈테일과 리본·청록
눈·성인 체형·짙은 오버핏 브이넥 니트·검은 이너와 스타킹을 모든 동작에서 유지하고, 휴대폰만
마권 안내·접수·발권 소품으로 교체했다. 배경은 2000년대 서울 경마장의 호두나무·아이보리·금장
창구이며 문자와 실제 상표는 금지했다. 접수 장면 초안에 생긴 외화 지폐는 이미지 편집으로 모두
제거하고 빈 금속 트레이와 무문자 단말만 남겼다.

암호화 피드 배지, 신호 아이콘, 스캔라인, 수평 레인 가이드, 출발 게이트, 먼지와 순위 UI는
Flutter 레이어로 합성한다. 결승선은 v4 파노라마에만 굽고 별도 Flutter 결승선은 그리지 않는다.
