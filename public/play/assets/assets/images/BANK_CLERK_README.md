# 윤하린 은행원 자산 규격

윤하린 은행원은 기존 디자인을 정체성 앵커로 유지하고 렌더링 화풍만
`SIMUL polished soft-render VN anime v3`로 전환한다.

## 반드시 유지할 디자인

- 같은 얼굴, 황금빛 눈, 긴 흑갈색 머리와 높게 묶은 헤어스타일
- 흰색 상의와 칼라, 버건디 넥타이, 남색 하이웨이스트 펜슬스커트
- 짙은 스타킹, 검정 펌프스, 통장·서류 등 은행 업무 소품
- 성인 여성 은행원으로 읽히는 기존 체형과 전체 실루엣

새 얼굴·새 헤어·새 의상으로 전면 재설계하거나 노출·길이·장식 구조를 임의로
바꾸지 않는다. 바꿀 수 있는 것은 선화, 채색, 명암, 피부·머리·천 재질감과 v3에
맞춘 마감뿐이다.

## 런타임 상태

| 상태 | 파일 | 역할 |
| --- | --- | --- |
| `welcome` | `character_bank_clerk_title_style_v2.png` | 첫 방문·통장 안내 |
| `explain` | `character_bank_clerk_explain_v2.png` | 금리·예금·신용 설명 |
| `approve` | `character_bank_clerk_approve_v2.png` | 가입·대출·상환 성공 |
| `concerned` | `character_bank_clerk_concerned_v2.png` | 한도 부족·실패·연체 경고 |

대표 `welcome` 한 장의 v3 렌더링을 먼저 승인받은 뒤, 같은 얼굴·헤어·체형·의상으로
나머지 세 상태를 확장한다. 네 파일은 공통 캔버스와 발 기준선, 투명 배경을 유지하고
흰색·짙은 회색 배경에서 알파 가장자리와 색 찌꺼기를 검수한다.
