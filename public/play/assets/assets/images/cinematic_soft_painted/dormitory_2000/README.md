# 생활실 배경 2종 · 런타임 호환 자산

1024×1536 PNG 카툰·소프트 페인터리 배경이다. 낮·밤 생활실은 현재 캠페인과
생활실 화면이 직접 사용한다. `future_academy`가 포함된 파일명은 내부 경로
호환용이며 사용자 화면에서 학교·학원 설정으로 해석하거나 노출하지 않는다.

| 파일 | 장면 | 상태 |
| --- | --- | --- |
| `bg_future_academy_dorm_shared_room_day_2000_v1.png` | 공용 생활실 낮 | 현재 런타임 |
| `bg_future_academy_dorm_shared_room_night_2000_v1.png` | 첫날 소등 뒤 | 현재 런타임 |

## 호환 규칙

- 신규 생성은 `art_references/simul_luminous_soft_painted_vn_style_anchor_v2.png`의 렌더링 문법을 따른다.
- 신규 데시멀 배경은 `../decimal/`에 두고 이 두 파일의 호환 경로를 늘리지 않는다.

## 승인 기준

- 따뜻한 실내광과 차가운 겨울 창밖광을 섞은 부드러운 페인터리 명암
- 실사·3D·굵은 검은 외곽선·하드 셀 채색 없음
- 남녀 색상 구역 없이 동일한 침구와 개인 수납을 사용하는 한 방 구조
- 화면 아래 28%도 정상적으로 그려져 있으며 대화창·검은 그라데이션이 없음
- 글자·로고·워터마크 없음

낮 생활실과 첫날 밤 생활실은 같은 카메라와 가구 배치를 유지하고 조명만 바꾼
연속 장면이다.
