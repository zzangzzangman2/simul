# 프로젝트 데시멀 여자 동기 8명 MBTI·대사 설계 인덱스

이 폴더는 프로젝트 데시멀 여자 동기 8명의 성격과 대사 일관성을 관리하는 정규 문서다.

이미지 재제작에서는 이 8명만 기존 얼굴·정체성·헤어·체형·의상·포즈·구도를 그대로
보존하고 `SIMUL polished soft-render VN anime v3`로 렌더링 화풍만 바꾼다. 공통 화풍
입력 순서와 검수는 `IMAGE_GENERATION_STYLE_PROMPT.md`와 `ART_STYLE_AUDIT.md`를 따른다.
신규 장면, 투자 의견, 생활실 갈등, 선택지 반응을 작성하기 전에 해당 인물 문서를 먼저 확인한다.

MBTI는 캐릭터를 찍어 내는 공식이 아니라 **정보를 받아들이고 결정을 시작하는 경향**을 구분하는 집필 도구로만 쓴다.
같은 유형이라도 가정사·관계·능력·현재 감정에 따라 행동은 달라질 수 있다.

## T/F 대사 적용 원칙

- T 네 명도 친구를 걱정하고 상처받는다. 다만 판단을 시작할 때 원인·규칙·효율·반례를 먼저 말한다.
- F 네 명도 계산하고 냉정하게 거절한다. 다만 결정이 사람·약속·가치·관계에 미칠 영향을 먼저 말한다.
- T가 항상 정답이고 F가 충동적이라는 구도를 금지한다.
- 같은 사건에서 T와 F가 서로 다른 위험을 발견하고, 두 관점을 합쳐야 완전한 판단이 되게 한다.

## 14살 인물 적용 원칙

- 성인 MBTI 소개문의 완성된 직업인처럼 말하지 않는다. 좋아하는 방식은 선명하지만 아직 과용하고 실수한다.
- 한 대사에는 주장 하나만 둔다. 설명문보다 반응·질문·말 끊기·정정이 먼저 나온다.
- 자기 유형을 입으로 설명하지 않는다. `나는 ENFP라서` 같은 메타 대사는 사용하지 않는다.
- 유형별 약점은 결함 낙인이 아니라 성장 장면과 선택 실패의 원인으로 쓴다.
- 스트레스에서는 선호 기능을 과하게 쓰지만, 사과와 회복에서는 반대 관점을 조금씩 배운다.

## 휴대폰·채팅 대사 강제 절차

휴대폰 메시지, 단체방, 문자, 쪽지, 댓글형 대사를 새로 만들 때도 장면 대사와 같은 기준을 사용한다.

1. 해당 인물의 개별 MD에서 `14살 성격`, `스트레스`, `대사 작성 규칙`, `휴대폰 메신저 적용`을 모두 확인한다.
2. 같은 사용자 메시지에 여덟 명이 무엇을 **먼저 보는지**를 각각 한 문장으로 적은 뒤 실제 답장을 쓴다.
3. 답장 속도·말풍선 수·문장부호·질문 방식까지 구분한다. 이름만 바꾸어도 성립하는 답장은 폐기한다.
4. 친밀도는 말투의 개방성과 공유 범위를 바꾸지만 핵심 판단축을 뒤집지 않는다.
5. T/F, E/I를 감정 유무나 말의 양 하나로 표현하지 않는다. 현재 감정·상황·관계가 MBTI보다 먼저 행동을 바꿀 수 있다.
6. 최종 검수에서 화자명을 가리고도 최소 6명 이상을 맞힐 수 없으면 다시 쓴다.
