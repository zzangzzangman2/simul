## 공통 승인 기준

- 실제 카메라로 촬영한 듯한 원근과 재질
- 낮에는 충분한 겨울 자연광, 밤에는 실용등과 창밖광으로 밝은 노출
- 그림자 속 가구와 이동 동선이 사라지지 않음
- 1981~2000년 한국 소품과 건축, 베이지색 CRT PC의 시대 정확성
- 사람·로고·읽을 수 있는 문구·워터마크 없음
- 하단 30%까지 완성된 배경이며 검은 대화창 그라데이션을 이미지에 굽지 않음
- 애니·카툰·페인터리 붓결·선화·셀 채색·3D/CGI 없음

주식 PC 실습실은 학생마다 컴퓨터 한 대를 쓰는 구성이며, 중앙 통로는 한서윤
캐릭터 슬롯을 위해 비워 둔다. 낮 생활실과 밤 생활실은 같은 카메라와 가구를
유지하고 시간대 조명만 다르다.
