# 주식 학원 선생님 캐릭터 메모

> 이 캐릭터는 투자학교 미연시와 주식시장 입문 튜토리얼의 한서윤 선생님이다.

## 고정 설정

- 나이: 21세 성인 여성
- 역할: 주식 투자 학원 선생님 및 주식시장 튜토리얼 안내자
- 체형: 성인 여성의 자연스러운 비율과 다리 볼륨
- 얼굴: 보라색 눈, 차분하고 친근한 인상
- 머리: 짙은 자주빛 갈색의 긴 로우 포니테일
- 의상: 아이보리 블라우스, 리본 타이, 네이비 스커트, 검은색 낮은 굽 구두
- 파일 배경: 알파 투명

## 자산 단계

- 이전 포즈 원본 시트: `06_6자세_블라우스_스커트_투명.png`
- 주인공 그림체 재생성 원본: `20_6포즈_주인공그림체_크로마.png`
- 크로마 제거 시트: `21_6포즈_주인공그림체_투명.png`
- 런타임 최종본: `22_포즈1`~`27_포즈6` (`1024×1536`)

포즈 순서는 왼쪽 위부터 다음과 같다. 얼굴·선화·채색 밀도는 `ART_STYLE_GUIDE.md`의 메인 타이틀 주인공 기준을 따르며, 구형 `14`~`19` 자산은 비교·호환용으로만 보존한다.

1. 지시봉을 든 기본 자세
2. 옆의 차트를 가리키는 자세
3. 마커와 펼친 손으로 설명하는 자세
4. 태블릿을 든 자세
5. 팔짱을 낀 자신감 있는 자세
6. 한 손을 허리에 두고 핵심 내용을 강조하는 자세

## 공통 캐릭터 슬롯 규격

- 캔버스: 투명 `1024×1536`
- 알파 인물 높이: 약 `1496px`
- 머리 여백: 약 `14~20px`
- 발 기준선: `y=1516`
- 발 중심/몸 중심 앵커: `x=512`
- 런타임: `Positioned.fill(bottom: 122) → LayoutBuilder → Align.bottomCenter → SizedBox(aspectRatio: 2/3, height: maxHeight×0.78)`
- 390×844: `left 7.28 / top 158.84 / width 375.44 / height 563.16 / bottom 722 / centerX 195`
- 360×800: `left 3.72 / top 149.16 / width 352.56 / height 528.84 / bottom 678 / centerX 180`

포즈 추가 시 얼굴·체형·의상은 유지하고, 새 포즈도 위 캔버스와 발/몸 앵커에 맞춘다. 장면별로 `left`, `top`, `scale`을 따로 만들지 않는다. 중앙 전신으로 추가되는 다른 등장인물도 같은 규격을 사용한다.
