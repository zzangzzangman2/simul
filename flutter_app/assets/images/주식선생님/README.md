# 주식 학원 선생님 캐릭터 메모

> 이 캐릭터는 투자학교 미연시와 주식시장 입문 튜토리얼의 한서윤 선생님이다.

## 고정 설정

- 나이: 23세 성인 여성
- 역할: 주식 투자 학원 선생님 및 주식시장 튜토리얼 안내자
- 최상위 그림체 기준: `art_references/simul_cinematic_soft_painted_style_v1.png`
- 얼굴·머리·눈 정체성 보조: `art_references/npc_canonical_style_teal_v1.png`
- 체형: 키가 크고 굴곡이 있으면서도 자연스러운 성인 여성 비율
- 얼굴: 보석처럼 여러 층의 하이라이트가 있는 보라색 눈, 작은 뷰티마크, 섬세하고 친근한 성인 인상
- 머리: 허리까지 내려오는 긴 물결형 청록색 머리, 성긴 일자 앞머리, 큰 덩어리·중간 가닥·잔머리와 띠 모양 하이라이트
- 의상 기준: `art_references/stock_teacher_outfit_reference_v1.png`
- 의상: 아이보리 반소매 오픈칼라 블라우스, 좁은 흰 레이스 안감, 사원증 목걸이, 흰 레이스 밑단의 검은 하이웨이스트 미니스커트, 차콜 시어 타이츠, 검은 앞막힌 펌스
- 파일 배경: 알파 투명

## 자산 단계

- 구형 갈색 머리 원본 시트: `06_6자세_블라우스_스커트_투명.png`
- 구형 갈색 머리 재생성 시트: `20_6포즈_주인공그림체_크로마.png`, `21_6포즈_주인공그림체_투명.png`
- **런타임 최종본**: 청록 머리·보라 눈·검은 레이스 스커트로 다시 만든 `22_포즈1`~`27_포즈6` (`1024×1536`)

구형 `05`~`21` 자산은 비교·복구용일 뿐 런타임에서 사용하지 않는다. 새 포즈의 얼굴·선화·눈·머리카락·채색 밀도는 `ART_STYLE_GUIDE.md`의 NPC 최상위 기준을 따른다.

1. 지시봉을 세워 든 환영 자세와 차분한 미소
2. 지시봉과 반대편 열린 손으로 차트를 설명하는 자세
3. 마커와 펼친 손으로 매수·매도를 비교하는 자세
4. 투자 교재를 두 손으로 안고 안내하는 자세
5. 두 손을 모으고 학생의 질문을 경청하는 자세
6. 한 손을 허리에 두고 검지를 들어 핵심 규칙을 강조하는 자세

## 공통 캐릭터 슬롯 규격

- 캔버스: 투명 `1024×1536`
- 알파 인물 높이: `1497px`
- 머리 시작: `y=20`
- 발 마지막 픽셀: `y=1516`
- 발 중심/몸 중심 앵커: `x=512`
- 런타임: 공통 캐릭터 부모의 `Positioned.fill(bottom: 0) → LayoutBuilder → Align.bottomCenter → SizedBox(aspectRatio: 2/3, height: maxHeight×0.9)`
- 모든 화면 크기에서 다른 중앙 전신 인물과 같은 부모·90% 높이·발 기준선을 공유한다. 과거 `bottom: 122`, `0.78` 배율로 되돌리지 않는다.

포즈 추가 시 얼굴 골격, 홍채의 하이라이트 구조, 청록색 머리 길이·앞머리·가르마, 체형, 블라우스 칼라·레이스·사원증·치마 밑단·타이츠를 그대로 유지한다. 새 포즈도 위 캔버스와 발/몸 앵커에 맞추며 장면별 `left`, `top`, `scale`을 따로 만들지 않는다. 중앙 전신으로 추가되는 다른 등장인물도 같은 캔버스 규격과 NPC 렌더링 문법을 사용하되 한서윤의 고유 머리·눈 색은 복사하지 않는다.
