# 시네마틱 프롤로그 런타임 자산

미참조 `policy_1981/` 24종과 구형 `dormitory_2000/` 4종은 2026-08-03에 삭제했다.

## 프로젝트 데시멀 배경

`decimal/`의 9:16 고해상도 11종이 선발 시험, 강남 센터, 생활·거래 허브를 담당한다.
국정원 도입부는 `decimal_nis_1999/`의 배경 2종·인물 6종을 사용한다. 세부 역할과
재제작 우선순위는 `DECIMAL_WORLD.md`, `HANDOFF.md`, `ART_STYLE_AUDIT.md`를 따른다.

실사·3D·굵은 검은 외곽선·현대 기기·읽을 수 있는 글자·로고를 넣지 않는다.
