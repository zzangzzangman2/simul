# Cinematic soft-painted anime realism 현행 인물·배경 자산

2026-07-31 제작 세트다. 실사 전환 작업을 중단한 뒤 이 폴더의 인물과 배경을
정식 카툰·소프트 페인터리 런타임 자산으로 복원했다.

## 공통 렌더링

- 스타일 기준: `art_references/simul_cinematic_soft_painted_style_v1.png`
- 애니메이션식 얼굴 구조에 부드러운 페인터리 피부·의상 명암을 결합한다.
- 외곽선은 거의 보이지 않는 유색 경계만 사용한다.
- 머리카락은 큰 실루엣, 중간 가닥, 잔머리와 섬세한 반사광을 모두 표현한다.
- 인물 스프라이트는 중립적인 확산광을 사용하고 배경 전용 bloom·bokeh를 굽지 않는다.
- 배경은 따뜻한 실내광과 차가운 창밖광, 은은한 bloom과 atmospheric depth를 허용한다.
- 실사 사진 얼굴, 3D, 플라스틱 피부, 치비, 굵은 검은 외곽선, 평평한 하드 셀 채색은 금지한다.

공통 원본은 렌더링 문법 전용이다. 원본 수아의 얼굴·긴 검은 머리·회갈색 눈·
체형·빨강 체크 교복은 수아만의 정체성이며 다른 인물에게 복사하지 않는다.

## 정책실 인물 버전

- 백기현과 강인철의 `*_v1.png`는 얼굴 유사 판정으로 승인 철회된 보관 자산이다.
- 런타임과 대사 편집기는 백기현 `01_report_v2`~`04_confirmation_v2`, 강인철 `01_calculation_v2`~`04_revision_v2`만 사용한다.
- 새 인물 생성 시 의상·안경·소품을 가린 얼굴 비교에서 기존 전체 등장인물과 즉시 구분되어야 한다.

인물 파일은 1024×1536 RGBA 투명 PNG다. 현재 런타임은 프롤로그 1~15번 장면과
수아 등장 장면에 이 자산을 정식으로 사용한다. 활성 정책실·기숙사 배경도 이
폴더의 카툰·소프트 페인터리 자산을 따른다.
