# 시네마틱 프롤로그 런타임 자산

이 폴더에는 현재 1981년 정책실과 1999~2000년 프로젝트 데시멀 센터에 연결된 카툰·소프트
페인터리 자산만 둔다.

## 1981년 정책실

- 배경: `policy_1981/backgrounds/` 2종
- 전두광: `policy_1981/jeon_dugwang/` 6종
- 서문태: `policy_1981/seo_muntae/` 4종
- 백기현: `policy_1981/baek_gihyeon/` v2 4종
- 강인철: `policy_1981/kang_incheol/` v2 4종
- 윤미라: `policy_1981/yoon_mira/` 4종

편집기 카탈로그의 파일명과 버전을 그대로 사용한다. 인물의 얼굴·복장·소품을
다른 정책실 인물과 섞지 않는다.

## 레거시 생활동 배경

`dormitory_2000/`의 4종은 구형 저장과 시각 비교에만 남긴다.

## 프로젝트 데시멀 배경

`decimal/`의 9:16 고해상도 11종이 신규 캠페인의 선발 시험, 강남 센터,
생활·거래 허브를 담당한다. 세부 역할은 `DECIMAL_WORLD.md`와 `HANDOFF.md`를 따른다.

신규 제작은 `ART_STYLE_GUIDE.md`의 공식 화풍과 어울리는 선·명암·색을 사용하고
실사·3D·굵은 검은 외곽선·현대 기기·읽을 수 있는 글자·로고를 넣지 않는다.
