# 국가망 온라인 경마 이미지

모든 파일은 프로젝트의 정식 v3 소프트 페인터리 앵커를 기준으로 ImageGen에서 새로
생성했다. 실제 경마장 상표·로고·읽을 수 있는 간판은 사용하지 않는다.

배경 생성 프롬프트는 2000년대 한국 오후 경마장, 관중석·그랜드스탠드·인필드·연못·
8개 주로 밴드·출발 게이트·아날로그 전광판을 요구하고 말·문자·로고를 금지했다. 질주
시트 프롬프트는 측면 전신, 8개의 서로 다른 실제 갤럽 단계, 일관된 말·기수 디자인,
고정 카메라와 평면 크로마 배경을 요구했다. 시트는 생성 후 크로마 제거·디스필·소프트
매트 처리를 거쳐 투명 PNG로 저장했다.

코너 배경은 서울 도심·산·관람석을 둔 높은 후방 방송 카메라, 완만한 좌회전, 서로
교차하지 않는 8개 레인과 자연스러운 소실점을 요구했다. 코너 말 시트는 각 정측면 시트를
정체성 참조로 넣어 털색·무늬·기수복을 고정하고, 후방 왼쪽 3/4 시점의 4×2 갤럽 단계로
다시 생성했다. 평면 녹색 크로마를 제거한 뒤 디스필·소프트 매트·1px 엣지 수축을 적용했다.

직선 주로 v2는 `stylized-concept` 모드에서 완전한 정측면·직교 카메라, 끝까지 수평이며
서로 평행한 8개 흙 레인, 긴 횡스크롤 구도, 2000년대 서울 외곽 풍경을 요구했다. 원근
수렴·대각선·커브·말·기수·출발 게이트·결승선·문자·로고·워터마크는 금지했다.

암호화 피드 배지, 신호 아이콘, 스캔라인, 카메라 컷 표식, 베지어 레인 가이드, 출발 게이트,
먼지, 속도선, 결승선과 순위 UI는 이미지에 굽지 않고 Flutter 레이어로 합성한다.
