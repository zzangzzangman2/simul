# 여자1 캐릭터 사용 메모

> 보관 전용 구형 자료다. 현재 기준 여자친구는 주인공과 동갑인 14살 캐릭터이며
> `../GIRLFRIEND_README.md`를 따른다. 기존 v3 6종도 연령 재검수 전에는 보관본이다.
> 아래 성인 임시 캐릭터와 새 여자친구의 얼굴·머리·눈·체형을 섞지 않는다.

이 폴더는 폐기된 성인 임시 캐릭터 `여자1`의 원본 보관 폴더다.
현재 여자친구 NPC 후보나 미연결 신규 자산이 아니며 런타임에 다시 연결하지 않는다.

## 고정 디자인

- 성인 여성 캐릭터
- 긴 애쉬브라운 머리와 옆 포니테일
- 금색 마름모 머리핀 2개
- 올리브 골드색 눈
- 가슴이 작은 슬림 체형
- 얼굴, 체형, 머리와 눈 색은 의상별로 바꾸지 않는다.

## 파일

- `01_교복_표정.png`: 교복풍 의상
- `02_평상복_표정.png`: 외출용 평상복
- `03_홈웨어_표정.png`: 나시티와 돌핀팬츠 홈웨어

각 파일은 왼쪽 위부터 `기본`, `미소`, `활짝 웃음`, `울음`, `삐짐`, `수줍음` 순서의 3×2 표정 시트다.

## 보관 규칙

1. 비교·복구용 원본으로만 둔다.
2. 현재 v3 여자친구 자산과 얼굴·머리·눈·체형을 섞지 않는다.
3. 대사창·이벤트·런타임 자산 목록에 다시 연결하지 않는다.
4. 다른 여자 캐릭터를 만들 때도 이 임시 인물의 얼굴이나 고유 머리 모양을 복제하지 않는다.
